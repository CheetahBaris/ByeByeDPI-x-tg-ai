# AI-подбор стратегий

Лаборатория сама подбирает стратегию обхода DPI: запускает движок на отдельном порту,
проверяет сайты, просит локальную или удалённую LLM предложить новые варианты и
применяет лучшую стратегию в настройки приложения.

Открыть: главный экран → меню **⋮** → **AI-подбор стратегий**.

> Перед запуском отключите основной VPN/Proxy приложения: лаборатория поднимает
> отдельный движок на порту `1081`.

## 1. Подключение к LLM

Поддерживается любой OpenAI-совместимый API: LM Studio, Ollama, llama.cpp, OpenAI.

### Модель на телефоне

1. Запустите локальный сервер, который слушает порт `1234` и открывает OpenAI API.
2. В поле **«Адрес API»** укажите `http://localhost:1234/v1` (или `http://127.0.0.1:1234/v1`).
3. В **«Как искать сервер»** выберите **«Локально (адрес из поля)»**.
4. Нажмите **«Найти сервер»** — проверяется ровно адрес из поля, без сканирования сети.

### Модель на компьютере по Wi-Fi

1. В LM Studio включите **Developer → Serve on Local Network**.
2. Телефон и компьютер должны быть в одной Wi-Fi-сети.
3. В **«Как искать сервер»** выберите **«Только Wi-Fi»** или **«Wi-Fi + USB-кабель»**.
4. Нажмите **«Найти сервер»**, выберите найденный адрес из списка.

### Модель на компьютере по кабелю (adb reverse)

```bash
adb reverse tcp:1234 tcp:1234
```

В поле адреса: `http://127.0.0.1:1234/v1`, режим поиска — **«Только USB-кабель»**.
Сеть телефона при этом может быть любой.

### Проверка подключения

Кнопка **«Проверить LLM»** обращается к адресу из поля и загружает список моделей.
Для `localhost`, `127.0.0.1` и `::1` сеть не привязывается — запрос идёт напрямую.

## 2. Сети

- **К модели (LM Studio)** — через какую сеть обращаться к LLM.
- **Сайты проверять через** — через какую сеть гонять тестовый трафик.

Типовая схема «LLM по Wi-Fi, тесты по LTE»: оставьте Wi-Fi включённым, для модели
выберите **Wi-Fi**, для сайтов — **Мобильная сеть**. Мобильные данные должны быть
включены. Отключите «Wi-Fi-ассистент»/автопереключение, иначе система сама сменит сеть.

**«Поднимать сеть, если она не активна»** — разрешает приложению запросить LTE,
когда Wi-Fi является сетью по умолчанию.

## 3. Параметры подбора

| Параметр | Смысл |
| --- | --- |
| Раундов | Сколько циклов «проверить → спросить LLM → проверить новое» делать |
| Повторов | Сколько раз проверять каждую стратегию на каждом сайте |
| Таймаут, с | Ожидание ответа сайта |
| Кандидатов | Сколько новых стратегий просить у LLM за раунд |
| Стоп без прироста | Остановиться, если несколько раундов нет улучшения |
| Параллельно | Одновременных проверок |
| Ответ, токенов | Лимит ответа LLM |
| Контекст | Контекст модели; для 8k хватает компактного промпта и базы по умолчанию |
| Ответ LLM, с | Сколько ждать ответ модели; для локальной модели на телефоне ставьте 300–900 |
| Автоматически применять | Сразу записывать лучшую стратегию в настройки |
| Переиспользовать baseline | Не мерить baseline каждый раунд |

### Промпт и база знаний

- Правила (роль, синтаксис `ciadpi`, диагностика, схема JSON) — **системное сообщение**.
- **База знаний** — редактируемый текст; он добавляется в то же системное сообщение,
  а не в запрос с результатами раунда. Галочка **«Отправлять базу знаний»** отключает
  её без удаления текста.
- Под полем базы показывается оценка: `правила + база + ответ` и лимит контекста.
  Если сумма больше контекста, строка подсвечивается красным.
- Кнопка **«Сбросить»** возвращает компактную базу по умолчанию.
- По умолчанию база занимает ~1.3 КБ; полная справка лежит в
  [BYEDPI_KNOWLEDGE.md](BYEDPI_KNOWLEDGE.md) и в промпт не отправляется.

### Длинные поля и уведомление

- У полей «Сайты», «Стартовые стратегии», «База знаний» и «Журнал» есть кнопка
  **«Развернуть»** — полноэкранный редактор/просмотр.
- Во время подбора в шторке висит уведомление: раунд, проверка `N/M`, лучшая стратегия,
  сайты/повторы и прошедшее время. Кнопка **«Остановить»** останавливает подбор.

## 4. Сайты и стратегии

- **Сайты для проверки** — по одному в строке, `#` начинает комментарий.
- **Загрузить** — готовые наборы: мобильный, YouTube, соцсети, Telegram, Discord и др.
- **Стартовые стратегии** — синтаксис `ciadpi`, по одной в строке.

## 5. Запуск и результаты

1. Нажмите **«Старт»**.
2. Следите за прогрессом и журналом. **«Скрыть»/«Показать»** сворачивает настройки.
3. **«Стоп»** останавливает подбор.
4. По завершении показывается лучшая стратегия и процент успешных проверок.
5. **«Применить»** записывает стратегию в настройки приложения (запущенный VPN будет перезапущен).
6. **«Топ»** — лучшие найденные стратегии, **«Отчёт»** — подробности последнего запуска,
   **«Очистить»** — очищает журнал.

Отчёты и топ сохраняются в `filesDir/lab` и доступны после перезапуска приложения.

## 6. Если не работает

| Симптом | Что проверить |
| --- | --- |
| «Сервер не найден» по Wi-Fi | «Serve on Local Network», одна сеть, брандмауэр, порт 1234 |
| Локальный сервер не найден | Сервер запущен на телефоне, слушает 1234, отвечает на `/v1/models` |
| По кабелю не находится | `adb reverse tcp:1234 tcp:1234`, режим «Только USB-кабель» |
| Модели не загружаются | Загрузите модель в LM Studio, проверьте `/v1/models` |
| Тесты идут не через ту сеть | Раздельные сети для LLM и тестов, отключите Wi-Fi-ассистент |
| Подбор не стартует | Отключите основной VPN/Proxy, порт 1081 должен быть свободен |
| Долго нет результата | Уменьшите «Раундов», «Повторов» и «Кандидатов», проверьте таймаут |
| «Таймаут LLM» | Увеличьте «Ответ LLM, с» (до 900 для телефона), уменьшите «Ответ, токенов» и «Контекст», отключите лишнюю базу знаний |
| Нет уведомления | Разрешите уведомления для приложения (Android 13+) |
| Промпт не влезает в контекст | Снимите галочку базы знаний, сократите её, уменьшите «Ответ, токенов» или поднимите «Контекст» |

Во время подбора экран не даёт устройству заснуть (флаг `KEEP_SCREEN_ON`).
При повороте экрана подбор продолжается.
